## Open defects

### B3 — A former folder rename restores access to a revoked broadcast (P2)

1. Broadcast to `team`, including recipient `b` in `team/sub`.
2. Move `b` individually to `other`: its notice is cancelled and agent retrieval
   correctly returns 404.
3. Rename `team` to `renamed`, leaving `b` in `other`.
4. `b` can retrieve the cancelled original-team message again in its new scope.

`SessionAPI.sync_memberships()` rewrites the broadcast root to the recipient's
current root without ensuring the recipient moved with the original scope.
The status remains cancelled; the defect is unauthorized scope rebinding, not
reactivation of the work. Still blocking; preserve the original regression.

### B4 — Release wheels omit the header icon and browser favicons (P2)

`App.tsx` loads `/favicon.svg`. The package-data declaration includes
`dashboard/index.html` and `dashboard/assets/*`, but omits the favicon files at
the dashboard root. The installed 0.4.47 package contains neither file.
`Server._dashboard()` substitutes index.html for the missing path, returning
HTTP 200 with HTML. The status alone is therefore not evidence the asset works.

Include both public favicon files in the packaged wheel and check their actual
content types/content from an installed wheel. The header image should have
nonzero natural dimensions. The native app icon is outside this finding.
